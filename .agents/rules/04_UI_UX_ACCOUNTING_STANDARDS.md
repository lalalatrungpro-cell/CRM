# DROPSHIP CRM - UI/UX & ACCOUNTING STANDARDS

## 🎨 UI/UX Action Buttons Standard (Orders Table Row)
Each order row in the main table MUST feature 5 distinct 360° action buttons in exact sequence:
1. `👁️` (Purple Eye): View Order 360° Detail Modal.
2. `🖨️` (Green Printer): Print Accounting Invoice.
3. `✏️` (Blue Pencil): Edit Account Credentials (`infor`), Supplier (`supplier_id`), Prices (`sell_price`, `cost_price`).
4. `🔄` (Orange Refresh): Warranty / Account Exchange.
5. `🗑️` (Red Trash): Delete Order.

## 💳 VietQR Composite PNG Image Standard
- VietQR copied image must be a composite PNG canvas card (`640px x 340px`).
- Left side: High-res VietQR code.
- Right side: Bank Name, Account Number (Bold Green), Account Owner, Amount (Bold Red), Transfer Memo (`DON #ID`).

## 💰 Currency & Date Formatting Standard
- Currency format: `150.000đ` (Vietnamese đồng with period separator).
- Date format: `YYYY-MM-DD` for inputs, `DD/MM/YYYY` for displays and invoices.
