# DROPSHIP CRM 360° - MASTER DIRECTIVE FOR AI

This repository contains **Dropship CRM 360°**, a specialized SaaS application for digital product dropshippers selling software accounts, SaaS subscriptions, and digital keys.

## 🎯 Primary Purpose & Goal
- **Product Vision**: Empower digital dropshippers to execute POS sales in <5s, maintain 100% supplier traceability, automate expiration renewals (+40% LTV), and prevent debt/warranty leakage.
- **Rule Set**: All AI agents working on this project MUST read and adhere strictly to the rules defined in `.agents/rules/`:
  - `00_PROJECT_MANIFESTO.md` - Core goals, target users, and vision.
  - `01_PROJECT_ARCHITECTURE.md` - Module map, routes, and data architecture.
  - `02_STRICT_TABOOS.md` - Mandatory taboos and forbidden patterns.
  - `03_CODE_VERIFICATION_WORKFLOW.md` - Code modification and verification rules.
  - `04_UI_UX_ACCOUNTING_STANDARDS.md` - UI/UX button standards, VietQR generator, and accounting tables.
